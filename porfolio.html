Powerlifting Tracker

A full-stack web app for logging training sessions and tracking progress toward a target weight class. Built with vanilla JavaScript on the frontend, a Node/Express backend, and a PostgreSQL database — with user accounts, JWT authentication, and live 1RM estimates for lifts without a logged max. Deployed on Netlify (frontend) and Railway (backend + database).
